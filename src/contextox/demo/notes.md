# 订单与客户：公开合成示例

这两张表全部为人工构造的演示数据，不对应真实客户或交易。
orders.csv 一行代表一笔订单，order_id 是订单标识；customers.csv 一行代表一个客户。
通过 customer_id 连接订单和客户，customer_name 仅用于展示，不用于连接或识别唯一客户。
amount 的币种为人民币，单位为元；是否包含税费及折扣尚未确定。
status 的样例包含 paid、refunded、pending；样例不代表完整枚举。
paid_at 记录支付时间，带有北京时间 UTC+08:00 的偏移；未支付订单可以为空。
按地区汇总金额时，纳入哪些订单状态、退款如何处理以及使用哪个时间字段归属日期，需要业务确认。
