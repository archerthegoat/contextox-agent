通过 CUA 操作实际 React 构建与 Python API，不通过原型代替生产交互。验收使用独立临时 SQLite 和合成 CSV；以下是工程浏览器证据，不是人工验收或模型质量证据。

- 首次没有工作区：直接发消息后建立“本地工作区”，保存会话与答复。

## 7. 批准后 Draft v2 修复与完整闭环复验
