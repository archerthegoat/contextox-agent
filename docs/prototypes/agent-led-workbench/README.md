# Agent 主导工作台：合成交互原型

本目录实现用户批准的「数契 Workbench：由 Agent 主导的交互重设计」方案第 1 个切片，供实现与浏览器交互核对参考。它是独立静态原型，不替代开发路径图、架构报告、既有合同或正式功能验收。

入口：`index.html`。可直接打开文件，或通过根代理提供的只读本地静态服务器，仅暴露本目录并访问 `/index.html`。无依赖、无需构建。Logo 和标准图标从仓库现有 `web/src/assets/` 原样复制到本目录 `assets/`，图标许可证随附。服务器仅应暴露本目录，不应暴露仓库根。

## 可以体验

- 顶部独立的「合成交互原型」场景选择：首次进入、任务前讨论、分析中、等待回答、回答卡片、草案更新、批准后续接失败、执行结果未知、已停止、连接提示。
- 首次进入点击「先帮我看看这两张表」，再点击「按地区整理订单金额」。分析在 3 秒后进入澄清，也可以使用明确标注的原型时间控制提前结束。直接选择「分析中」场景会停在此状态，便于检查布局和停止操作。
- 等待回答时可以询问原因，使用完整示例回答产生可编辑卡片；修改会改变回答版本。「仅保存」不批准、不执行；「确认并继续」保存批准并启动单次后续分析。
- 批准后续接失败分别显示批准成功、分析未启动；重试只启动后续分析。未知结果场景先核对合成回执，再解锁发送。分析期间可编辑草稿、停止，不排队。
- 资料引用/左侧资料导航打开中间预览并暂停自动跟随；「跟随当前进展」恢复。新的结果不抢走手动查看的内容。
- 右栏分隔线：Pointer 拖动、左右方向键每次 24px、Home 或双击恢复默认。默认剩余宽度 44%，初始 360–640px；桌面两面板最少 360px。只保存面板宽度偏好到 localStorage。
- 展开对话/恢复双栏；960px 以下默认展示对话，顶部切换工作区，导航抽屉可打开。
- 资料选择保持当前对话的合成范围；本地文件选择只显示文件名，不读取、不上传、不加入分析。
- 连接提示不接受真实密钥。通过明确标注的模拟连接选择，可以体验「仅保存设置」与「保存并发送这条消息」的区别。

## 数据与边界

所有业务资料来自仓库公开合成 `src/contextox/demo/orders.csv`、`customers.csv` 和 `notes.md`。回答内容是显式演示规则，不是真实用户事实。没有复制原始 fixture 文件，没有引入真实数据、Provider、密钥、后端调用或上传。任意文本只显示在本页内存中，未匹配的对话明确提示原型只支持固定流程；不要输入私人资料。刷新会重置对话、任务、回答、资料选择和合成回执，不证明持久化、权限校验或真实幂等。

此原型可用于浏览器外观/交互检查；真实服务、持久化迁移、模型对话、权限、批准幂等、真实 SSE、真实集成和人工验收均未由本目录实现或证明。正式 Contract、任务完成、跨任务复用和云端能力不在本目录范围。
