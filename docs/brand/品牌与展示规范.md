# 数契品牌与展示规范

状态：首批展示包实施基线。适用于 Demo 1.0.0 的落地页、动态介绍、视频和电子物料，不改变产品路线图、架构合同或产品能力状态。

## 1. 传播目标

首批材料用于分享会和项目展示。观众应在三分钟内理解：数契解决什么业务问题；Agent、人和证据如何协作；当前 Demo 可以体验什么；在哪里查看源码或参与项目。

主张固定为：

> 让每一张表，都说清自己代表什么。

补充说明固定为：

> 数契把表格、说明和人的判断，整理成有证据、可确认的业务定义。

首批故事统一使用公开合成的订单与退款案例：用户想按地区统计订单金额，但退款、缺失金额和时间范围尚未明确；Agent 定位证据、提出具体问题，人核对回答后，候选字段、关系与未知事项发生可回读的变化。

## 2. 事实与表述边界

- 当前版本统一标记为 `Demo 1.0.0`。
- 可以表述已经具备连续对话、精确资料范围、澄清卡片、确认续接、候选字段与关系、引用、导出和失败恢复。
- 当前结果称为“候选业务定义”或“可核对的候选成果”。正式 Contract 发布和跨任务批准知识复用属于后续开发。
- 工作区、资料和状态保存在本机；发送消息时，明确选择的资料范围和必要上下文会交给 DeepSeek。
- 当前 Release 提供源码和公开合成示例，没有预构建安装包。
- 不使用未经验证的提效数字、客户评价、客户标志、生产稳定性或“完全离线”等表述。

## 3. 视觉合同

视觉主题是“定义工作台”：背景像浅色工作纸，结构线表达资料、问题、确认和成果之间的关系；界面截图保持真实原色；蓝色只用于主动作、当前步骤和证据定位。

| 角色 | 颜色 |
| --- | --- |
| 页面背景 | `#f5f7fa` |
| 主表面 | `#ffffff` |
| 主文字 | `#13243a` |
| 次文字 | `#607086` |
| 结构线 | `#dce3eb` |
| 强结构线 | `#bcc8d6` |
| 品牌蓝 | `#1674f3` |
| 品牌浅蓝 | `#eef5ff` |
| 已确认 | `#147d64` |
| 待确认 | `#a76a08` |

中文与界面沿用系统字体栈：`-apple-system, BlinkMacSystemFont, "Segoe UI", "PingFang SC", "Hiragino Sans GB", sans-serif`。代码和版本使用 `SFMono-Regular, Menlo, Consolas, monospace`。

版式要求：优先左对齐；标题与正文之间保持明显层级；一屏只有一个主信息；产品截图不叠加长文案；避免装饰性玻璃、霓虹、通用 AI 光球和持续漂浮动效。动效只用于揭示关系、说明状态变化和提示当前焦点。

## 4. Logo 使用

保留现有蓝色圆环与斜切连接符号的识别。首批提供图标、横版字标、反白和单色 SVG，并从同一 SVG 导出所需 PNG。

- 图标周围安全区至少为图标直径的 `1/6`。
- 图标单独使用时建议不小于 24 像素；16 像素只用于 favicon。
- 浅色背景使用品牌蓝，深色背景使用白色反白版本。
- 不旋转、不拉伸、不增加阴影或渐变，不把图标替换成字母 O。

## 5. 交付一致性

落地页、动态介绍、视频和电子物料使用相同名称、主张、案例和行动入口。真实产品画面标记“公开合成演示”；讲解用的交互模拟标记“讲解模拟”。视频、网页和 PDF 的人工验收绑定精确提交或导出文件，不能互相代替。
