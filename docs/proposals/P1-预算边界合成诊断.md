## 观察结果

| 合成实验 | 结果 | 能证明什么 |
| --- | --- | --- |
| 同一3000字节正文放在一个SSE事件 | wire3272字节；成功，收全3000正文，usage已知 | 小封装下该内容可以解析完成 |
| 同一正文拆为3000个SSE事件 | wire324165字节；在收到2427正文后context_budget_exceeded，usage未知 | 累计SSE传输封装同样消耗262144上限，不能从错误码推断是请求上下文太大 |
| 语义缓冲恰好262144字节后再加1字节 | 明确拒绝 | 内容累积也使用相同错误 |
| Agent跨模型轮次公开文本累积到262144后再加1字节 | 明确拒绝 | 错误可能发生在Agent跨轮累积，不能假定是Provider请求前 |
| 超长IPC result | 转为context_budget_exceeded且usage未知 | IPC也可产生相同错误，不能据此断言没有发出请求 |
| 序列化请求超限 | 错误发生前fake transport调用次数0 | 存在请求前的同名错误分支，需区分阶段 |

同一正文的两个对照都是有效合成事件流；现有传输总量守卫按代码生效，并非本轮已经证明可直接删除的缺陷。更细分片会放大封装开销，这是对话可用性风险；必须保留有限内存/传输/时间保护。

历史真实运行没有保存原始Provider流，不能从本实验回溯它究竟撞到了哪一个边界。其精确触发层仍UNKNOWN；这次没有修复或真实复验的PASS。

建议先补固定stage与有界字节计数的内部诊断，保持外部code和预算数值不变。是否分离SSE传输预算、内容预算和IPC限额，需有独立精确数值、兼容与极端分片反例后再批准；不在本轮偷偷提高上限。

### 提案DDL检查

```python
import re,sqlite3,tempfile,json
from pathlib import Path
from contextox.store import WorkspaceStore, WorkspaceSchemaUnsupportedError
text=Path("docs/proposals/P0-任务对话与执行续接契约-v1.md").read_text()
ddl=re.search(r"```sql\n(.*?)```",text,re.S).group(1).strip()
with tempfile.TemporaryDirectory(prefix="contextox-p0-ddl-") as d:
    store=WorkspaceStore.open(d)
    with sqlite3.connect(store.db_path) as db:
        db.execute("PRAGMA foreign_keys=ON")
        before=db.execute("SELECT name,sql FROM sqlite_master WHERE type='table' ORDER BY name").fetchall()
        assert db.execute("PRAGMA user_version").fetchone()[0]==3
        db.execute("BEGIN IMMEDIATE"); db.execute(ddl); db.execute("PRAGMA user_version=4"); db.rollback()
        assert db.execute("PRAGMA user_version").fetchone()[0]==3
        assert db.execute("SELECT name,sql FROM sqlite_master WHERE type='table' ORDER BY name").fetchall()==before
        db.execute("BEGIN IMMEDIATE");db.execute(ddl);db.execute("PRAGMA user_version=4");db.commit()
        assert db.execute("PRAGMA foreign_key_check").fetchall()==[]
        try:
            db.execute("INSERT INTO run_message_inputs VALUES(?,?,?,?,?,?,?)",("w","m","r","msg",1,"[]","[]"))
        except sqlite3.IntegrityError: db.rollback()
        else: raise AssertionError("foreign key did not reject")
        after=db.execute("SELECT name,sql FROM sqlite_master WHERE type='table' AND name!='run_message_inputs' ORDER BY name").fetchall()
        assert before==after
    try: WorkspaceStore.open(d)
    except WorkspaceSchemaUnsupportedError: pass
    else: raise AssertionError("old app must reject proposed v4")
```
