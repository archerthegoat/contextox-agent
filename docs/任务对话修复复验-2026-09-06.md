## 改动及原因

- F1：本轮事件读回同时更新 Mission 与 Run；“刷新对话”核对完整任务、执行与消息，保留草稿。若另一个客户端已经推进当前任务，刷新会对齐最新执行，仍按 Workspace/Mission/Run 身份和版本防止旧响应覆盖。
- F2：服务端事件流在匹配的运行工作线程结束前不会仅因终态收据出现而关闭；工作线程结束时唤醒等待者。前端保持当前执行订阅到终止事件，不因提前读到 partial 而改成一次性历史回放。尚在核对时使用核对提示，不将缺少一次快照中的公开输出判成答复丢失。
- F3：依据当前草案、澄清、引用，以及最多四条历史所属 Run 的确切来源，列出尚未明确选择的资料。未核清范围或缺少资料时不能提交；用户在输入区勾选后才纳入本轮范围。引用和浏览本身不扩大权限。

未改变 HTTP/JSON/SSE 字段、数据库 schema、预算、提供商或依赖；未读取 .env、调用真实模型或迁移私有资料。开发路径图、受控架构报告未修改。
