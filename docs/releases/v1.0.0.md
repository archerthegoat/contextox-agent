# 数契 Demo 1.0.0：从对话开始整理业务定义

**发布状态：RELEASED · DEMO**

- 目标版本：`1.0.0`
- 发布日期：2026-09-11
- Git 标签：`v1.0.0`
- GitHub Release：[数契 Demo 1.0.0](https://github.com/archerthegoat/contextox-agent/releases/tag/v1.0.0)
- 交付形式：源码 Release 与公开合成示例；暂不包含预构建安装包

1.0.0 是数契首个面向推广的初始 Demo。它把原来需要理解 Mission、Run 和 Provider 的操作，收进一个连续对话：用户从右侧说出目标，Agent 理解明确选择的资料、提出会改变结论的问题，并把候选字段、关系和业务口径放到中间工作区核对。

## 这一版解决什么问题

业务定义常散落在表格列名、说明文档和人的经验里。直接让模型输出一个答案，很难知道它依据什么，也很难区分观察到的事实、人的确认和仍然未知的事项。

数契 1.0.0 把这段工作组织为一条可追溯的链路：

1. 明确选择本次对话的资料版本。
2. 用自然语言讨论目标；信息足够后，发送即开始分析。
3. Agent 整理字段和关系，引用可以定位回资料。
4. 会改变结果的业务规则进入回答卡片。
5. 人核对后点击一次“确认并继续”，系统保存回答、记录批准并续接分析。
6. 中间区域展示候选变化、仍未知事项和后续动作。

## 主要变化

### 对话成为主入口

- 无任务时也能直接讨论资料和业务问题。
- 输入框固定在右侧底部，发送后按当前状态讨论或推进。
- 对话内提供由产品状态决定的下一步按钮，帮助用户添加资料、了解资料、回答问题或查看成果。
- 模型未连接时保留原消息，并明确区分“仅保存设置”与“保存并发送这条消息”。

### 中间工作区解释过程

- 常驻“明确目标 → 理解资料 → 澄清口径 → 整理成果”阶段。
- 固定回答“正在做什么 / 需要你做什么 / 已经得到什么”。
- 新成果和新问题同时出现时，优先展示刚更新的字段与关系，右侧继续提示剩余问题。
- 手动查看资料时保留当前位置，通过“跟随当前进展”恢复联动。

### 关键决定仍由人确认

- 自然语言回答先整理成可修改卡片，不会直接成为批准。
- 回答来源、依据和未知事项都保留。
- “确认并继续”内部使用独立幂等身份保存、批准和续接；刷新或重复操作不会重复启动同一轮分析。

### 技术信息分层展示

默认页面显示业务名称、自然语言结论、资料名、下一步和未知项。字段标识、版本、Run ID、哈希、Provider 预算与收据放在可展开的技术详情中。

## 体验方式

打开工作台后点击 **体验示例**，可以先查看无需 Key 的公开合成预览。点击“载入示例，亲自运行”会创建新的本地工作区；配置 DeepSeek Key 并明确发送后，才会调用模型。

推荐演示路径：

1. 添加订单与退款资料。
2. 点击“了解本轮资料”，先进行任务前讨论。
3. 发送“我想按地区统计订单金额，并把退款和缺失金额的处理规则写清楚”。
4. 在澄清期间追问原因，再用自然语言回答规则。
5. 核对回答卡片，点击“确认并继续”。
6. 在中间查看候选字段、地区关系、回答带来的变化和剩余未知项。

## 从源码启动

Demo 1.0.0 当前提供 GitHub 自动生成的源码压缩包。开发环境需要 Python `3.14.7`、UV 和 Node.js `22.19.0` 以上版本：

~~~sh
git clone --branch v1.0.0 --depth 1 https://github.com/archerthegoat/contextox-agent.git
cd contextox-agent
uv sync --locked
npm --prefix web ci --ignore-scripts
npm --prefix web run build
uv run --locked contextox start --agent-profile demo-fast --open-browser
~~~

预构建 macOS Apple 芯片安装包仍在准备中，不属于本次 Demo 1.0.0 Release。

## 数据与安全边界

- 服务只绑定 `127.0.0.1`。
- 工作区、资料、对话、草案、回答和记录保存在本机。
- 只有本轮明确选择的资料范围和必要上下文会在发送时交给 DeepSeek。
- Key 默认保存在 macOS Keychain，不写入工作区数据库或浏览器存储。
- 不支持远程访问、多用户协作、任意文件枚举、SQL 或 Shell 执行。

## 已知边界

- 输出仍是候选草案，不是正式发布的 Contract。
- 仅提供单一 DeepSeek Provider。
- 首个运行包仅面向 macOS Apple 芯片。
- 大文件、Windows / Linux、云同步、跨任务知识复用和多用户协作不在 1.0.0 中。
- 真实模型稳定性、用户价值与正式人工验收需要分别记录。
